# DR. SHAMSUL ALAM — WORDPRESS THEME (PRECISION IN PAIN CARE)

A bespoke, light luxury medical editorial WordPress theme designed specifically for **Dr. Shamsul Alam (Pain Medicine Specialist)**.

---

## 🌟 KEY FEATURES

1. **Light Premium Medical Aesthetic**:
   - Palette: Warm White (`#FAFAF7`), Soft Ivory (`#F3F5F2`), Pure White (`#FFFFFF`), Deep Charcoal (`#18212B`), Soft Medical Teal (`#3D9C98`), Muted Sky Blue (`#7BAFC4`).
   - Generous whitespace, razor-sharp Swiss typography hierarchy, zero template bloat.

2. **Custom Post Types (Built-in)**:
   - `condition`: Pain conditions (Spine, Nerves, Joints, Musculoskeletal) with categorized taxonomy.
   - `treatment`: Interventional procedures (Fluoroscopy, Ultrasound, Radiofrequency, Injections).
   - `chamber`: Practice locations, visiting days, timings, serial booking numbers.
   - `faq`: Patient clinical education accordions.

3. **High-Conversion Clinical Booking Engine**:
   - Integrated modal appointment booking system.
   - Intelligent auto-selection of chamber location and pain complaint.
   - Built-in WordPress AJAX handler (`dr_shamsul_booking`) with secure nonce verification.

4. **SEO & Structured Data**:
   - Embedded Schema.org `Physician` and `MedicalProcedure` JSON-LD schema.
   - Semantic HTML5 markup throughout.

5. **Mobile First Responsive Design**:
   - Persistent quick-action bar for mobile devices (Call, WhatsApp, Book Appointment).

## 🚀 INSTALLATION INSTRUCTIONS

### Option 1: Direct WordPress Admin Upload (.zip)
1. Download or zip the folder `dr-shamsul-alam` into `dr-shamsul-alam.zip`.
2. In your WordPress dashboard, navigate to **Appearance > Themes > Add New Theme**.
3. Click **Upload Theme**, select `dr-shamsul-alam.zip`, and click **Install Now**.
4. Click **Activate**.

### Option 2: FTP / Hosting File Manager
1. Upload the unzipped `dr-shamsul-alam` folder directly into:
   `/wp-content/themes/dr-shamsul-alam/`
2. Go to **Appearance > Themes** in your WordPress admin panel.
3. Click **Activate** on **Dr. Shamsul Alam - Pain Medicine Specialist**.
